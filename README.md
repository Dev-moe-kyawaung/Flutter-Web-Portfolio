# Moe Kya Waung - Developer Portfolio

🎉 **This is an amazing flutter web portfolio** showcasing my skills in mobile and web development!

## 🌟 Features

✨ **Modern Design** - Beautiful UI with gradient backgrounds and animations
📱 **Responsive** - Works perfectly on mobile, tablet, and desktop
🎨 **Interactive** - Hover effects, smooth animations, and scroll effects
📦 **Project Showcase** - Display your best projects with descriptions and links
📧 **Contact Form** - Integrated contact form to receive messages
🔗 **Social Links** - Connect to GitHub, Twitter, LinkedIn, etc.

## 🚀 Technologies Used

- **Flutter** - Cross-platform framework
- **Dart** - Programming language
- **Google Fonts** - Beautiful typography
- **Animated Text Kit** - Text animations
- **URL Launcher** - Open links

## 🏃 Getting Started

### Prerequisites
- Flutter SDK (v3.0.0 or higher)
- Dart SDK

### Installation

```bash
# Clone the repository
git clone https://github.com/Dev-moe-kyawaung/portfolio

# Navigate to project
cd moe_kyawaung_portfolio

# Get dependencies
flutter pub get

# Run the app
flutter run -d chrome
```

## 🎯 Customization

### Update Your Information

1. **main.dart** - Change app title and theme
2. **hero_section.dart** - Update name and gravatar URL
3. **about_section.dart** - Modify your bio and skills
4. **project_model.dart** - Add your projects
5. **contact_section.dart** - Update contact details

### Change Colors

Edit the color constants in theme configuration:
```dart
primaryColor: const Color(0xFF1A237E),  // Primary Blue
Colors.cyan,  // Accent Color
```

## 🌐 Deploy

### Deploy to Firebase Hosting

```bash
firebase login
firebase init hosting
flutter build web
firebase deploy
```

### Deploy to Vercel

```bash
vercel
```

### Deploy to Netlify

```bash
npm install netlify-cli -g
netlify deploy --prod --dir=build/web
```
